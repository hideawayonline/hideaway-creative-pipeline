# hideaway. — Designer Dupe Bottle Sourcing Sheet (Genuine Empties Only)

**Goal:** buy one genuine EMPTY bottle of each designer fragrance our perfumes are inspired by, as cheaply as possible, shipped/picked up to Steve's home address. Props for marketing videos and images (dupe bottle beside the hideaway product, per house creative style).

**Rule: real bottles only — no replicas/lookalikes.** Researched 21 Jul 2026. Prices AUD. Two channels:

1. **Facebook Marketplace / Gumtree (cheapest)** — locals sell empty designer bottles in $10–20 bulk lots (benchmark: a live $12 listing with 5 genuine bottles incl. Flowerbomb). Account/location-bound, so Steve runs these searches himself using the scripts below.
2. **eBay AU (searchable + negotiable)** — genuine empties, Best Offer haggling. **Always filter Item location: Australia** — US listings routinely triple in price once postage lands (seen: $23 bottle + $58 postage).

> Listing links below marked *(unverified)* came from search snippets — marketplaces block automated page checks, and listings churn weekly. The search URLs are the durable tool: open, sort by *Price + postage: lowest*, filter to Australia.

## 3. Negotiation playbook (copy-paste)

### eBay Best Offer (listings with "Make Offer")
> Hi! I'm buying several empty perfume bottles for a photography project. Would you take $X for this one? Happy to pay right away. If you have any other empty designer bottles, I'd love to bundle and pay one combined postage. Thanks!

Rule of thumb: offer 50–60% of asking. Empties have almost no market floor — sellers usually accept or counter close.

### eBay seller with multiple empties (combined postage)
> Hi! I can see you sell a few empty fragrance bottles. I'm putting together a set for a photo shoot — if I buy [list], could you do $X total including combined postage to [postcode]? Can pay today.

### Facebook Marketplace — search terms (run on Steve's account)
Sorted "Date listed: newest first", save each search for alerts:
- `empty perfume bottles` (bulk lots — best value)
- `empty perfume bottle` (singles)
- `perfume bottle collection`
- `[fragrance name] empty` for priority bottles (e.g. `black opium empty`, `baccarat rouge empty`)

### Facebook Marketplace message (single listing)
> Hi! Is this still available? I'm collecting empty designer bottles for a photography project — would you take $X if I [pick up this week / cover postage]?

### Facebook Marketplace "wanted" post (local buy/sell groups — often turns up freebies)
> Looking to buy empty designer perfume bottles (Dior, YSL, Chanel, Tom Ford, Kayali etc.) for a photography project — paying a few dollars each, happy to pick up. Check your dresser before you toss them!
