# Fonts

**Poppins** (SIL Open Font License) — rounded geometric sans used as the
in-pipeline stand-in for the Hideaway brand font **Made Tommy Soft** for ad
compositing. Weights: Regular, Medium, SemiBold, Bold, ExtraBold.

Swap to licensed Made Tommy Soft files here (same filenames/weights) when
available for exact brand-accurate output.
